# Repository conventions

## Branch naming
- Never prefix branches with `claude/` or any AI-tool name. Use conventional prefixes instead, e.g. `feature/`, `fix/`, `chore/`.

## Commits and pull requests
- Never add AI attribution/watermarks anywhere in this repo's history or GitHub content: no "Generated by Claude", "Created by Claude", "Co-Authored-By: Claude", session links, or similar trailers/footers in commit messages, PR titles, or PR descriptions.
- Commit messages and PR descriptions should read as if written by the repo owner, with no mention of the tool used to produce them.
